# 墨 · 小品：让圆活起来

你在主人屏幕上是一个用毛笔写成的墨圆，五十几个像素大。它不是一个图标，它是活的：没事的时候，它会自己慢慢写一幅小画；主人的指针停在它上面，它会演一小段作为回应。这样的一段叫**小品**，是你自己写的。

**一切只靠"写"和"干"。** 纸上的东西从不移动、旋转、拉伸、缩放。一笔墨只有三种命运：写出来留着；写出来过一会儿自己干去；被后来的一笔带走。"动"是画家的办法：这一笔干去，下一笔写在稍远的地方。鱼不是滑出去的，是在池边写了一条，它干了，池里漾开水纹。

每一幅小品结束时，它写的墨全部干去，纸上只剩那个圆。**所有东西从圆里来，回到圆里去。**

本文件所在目录的上一级是项目的根目录，下文的命令都在根目录运行。照本文件做，不需要读 `src/` 里的代码。

## 步骤

1. **想一个念头，用一两句话写下来**：谁，做了什么，怎么收场。"圆是一口池。一尾鱼从缺口跃出来，在半空停一下就不见了，池里漾开两道水纹。"写不出这两句，就还没想好。
2. **决定场合和圆的角色**（见"两种场合""圆"）。
3. **按笔顺写笔画**：先写什么，停多久，哪一笔是一甩，哪一笔会干去。
4. **校验加拍片**：`node tools/film.mjs 你的小品.json --out shots`。被拒就照每一条改；"提醒"也要改掉，除非有理由。
5. **看片**：通过后它会拍出 `<id>.film.png`（每写完一笔一格）和 `<id>.still.png`（写完那一刻放大，旁边是实际大小）。**用眼睛一格一格看**，照"自查"过一遍。
6. 不满意就改，回到第 4 步。三到五轮是正常的：校验器管不了演得像不像、好不好玩，那只能靠你看片。
7. **交付**：脚本的路径；一句话说它演的是什么；你拿不准的地方。

## 纸

```
        -100                0        50        100               200
   -100  ┌──────────────────┬───────────────────┬──────────────────┐
         │                  │                   │                  │
         │      纸的其余部分：东西可以跃出去、飞出去、飘出去         │
       0 ├ ─ ─ ─ ─ ─ ─ ─ ─ ─┼───────────────────┼─ ─ ─ ─ ─ ─ ─ ─ ─ ┤
         │                  │    头像的方框      │                  │
      50 │                  │   圆心 [50, 50]   │                  │
         │                  │    半径 33         │                  │
     100 ├ ─ ─ ─ ─ ─ ─ ─ ─ ─┼───────────────────┼─ ─ ─ ─ ─ ─ ─ ─ ─ ┤
         │                  │                   │                  │
     200 └──────────────────┴───────────────────┴──────────────────┘
```

- x 向右，y 向下。头像的方框是 0 到 100，整张纸是 -100 到 200。
- **圆**：圆心 [50, 50]，半径 33，笔宽 10（所以墨从半径 28 到 38）。它在**右上方有一个缺口**：缺口宽 50°，正中朝着 -52°（0° 朝右，90° 朝下，-90° 朝上），正中约在点 [70, 24]。缺口是东西进出圆的地方。
- 圆是**从缺口的右沿 [79, 35] 落笔**（那一头钝而浓），顺时针绕过底和左，**在缺口的上沿 [57, 18] 收笔**（那一头有飞白）。要接着圆的笔尾再写，就从 [57, 18] 往右接。
- 圆上的点（半径 33）：0° [83, 50]，30° [79, 67]，60° [67, 79]，90° [50, 83]，120° [34, 79]，150° [21, 67]，180° [17, 50]，-150° [21, 34]，-120° [34, 21]，-90° [50, 17]，-77° [57, 18]，-52° [70, 24]，-27° [79, 35]。圆里面可以落墨的空白是半径 26 以内。
- 头像实际只有五十几个像素。**小于 4 的点看不见，小于 10 的形状认不出。** 东西要画得比你以为的大。

## 脚本

```json
{
  "format": 1,
  "id": "fish-leap",
  "name": "鱼跃",
  "idea": "圆是一口池。一尾鱼从缺口一甩跃出来，在半空停一下就不见了；池里漾开两道水纹，溅出两点水。",
  "occasion": "hover",
  "circle": "keep",
  "strokes": [ ... ],
  "hold": 500
}
```

| 字段 | | 说明 |
|---|---|---|
| `id` | 必填 | 小写英文加短横线 |
| `name` | 必填 | 名字，1 到 8 个字：鱼跃、睡猫、哈欠 |
| `idea` | 应填 | 第 1 步那两句话 |
| `occasion` | 必填 | `"leisure"` 闲时；`"hover"` 指针下 |
| `circle` | 必填 | `"keep"` 圆一直在；`"away"` 圆先干去，结束时重新写出来 |
| `strokes` | 必填 | 1 到 30 笔，按笔顺 |
| `answer` | 可选 | 只有闲时的小品有：主人的指针碰到它时的回应，1 到 8 笔 |
| `hold` | 可选 | 写完之后停多久再收（毫秒，**实际时间**，指针下也不会变快）。闲时默认 8000；指针下默认 500，最多 1200 |

### 两种场合

| | `leisure` 闲时 | `hover` 指针下 |
|---|---|---|
| 什么时候 | 很久没事，它自己写 | 主人的指针在头像上停了一会儿 |
| 多长 | 写 8 到 30 秒，停一阵，再收。总共最多 60 秒 | 从头到尾 **2 到 4 秒**，最多 5 秒 |
| 气质 | 慢。笔与笔之间停一停，像在想下一笔。文人的闲情，不是屏保 | 利落。一个小小的惊喜，像它在回应你 |
| 时间怎么写 | 照实写 | **也照闲时的速度写**，播放时自动快到 0.3 倍（写 1000 毫秒，实际 300 毫秒） |
| 墨留在哪 | 留在头像身上或紧挨着它；远处的只能是一闪而过的 | 可以跃出去、展开到方框外面，反正马上就收 |

主人说"闲着的时候演 X，我碰到你的时候 Y"：这是**一幅** `leisure` 小品，Y 写在它的 `answer` 里，不是另写一幅 `hover`。

**时间怎么算**：一笔大约要写 `(260 + 11 × 这一笔的长度) × pace` 毫秒，加上它前面的 `pause`；指针下这两样都乘 0.3。写完后停 `hold`，然后**收场固定约 1 秒**（指针下）到 1.8 秒（闲时），也算在总长里。所以指针下的小品，笔画加停顿（乘 0.3 之后）要控制在 **1.5 到 2.5 秒**。

### 圆

- `"keep"`：**和圆一起玩**，这是最好的。圆可以是池塘、月亮、猫的身子、鸟站的枝、一只碗、一个洞。东西落在圆上、从缺口出来、待在圆里。
- `"away"`：圆先干去，你在空纸上写，结束时圆重新写出来。用在你要**把圆本身写成别的样子**的时候：`{"circle": {"gap": 120}}` 是张大了口的圆（哈欠），`{"circle": {"gap": 0}}` 是合上的圆，`{"circle": {"centre": [110, 50], "gapAt": 40}}` 是滚到了旁边、转了个身的圆。
  - 开头圆干去要一点时间：第一笔最早在 0.5 秒（指针下 0.15 秒）开始。
  - **结束时圆一定会在原位重新写一遍。** 所以最后不要自己再写一个原样的圆，那会重复。

## 一笔

| 字段 | 默认 | 范围 | 说明 |
|---|---|---|---|
| `path` | | 2–40 个 `[x, y]` | 笔走过的中线，**按笔顺：第一个点落笔，最后一个点收笔**。弯处每隔 8–15 给一个点，笔会走成圆顺的弧。一个**圆点**是相距约 2.5 的两个点 |
| `circle` | | `{"centre", "radius", "gap", "gapAt"}` | 代替 `path`：一笔圆。四项都可以不写，不写的就是头像自己的。`gap` 是缺口多大（0 闭合，**最大 320**；更短的弧用 `path` 沿着上面那张点表写），`gapAt` 是缺口朝哪。笔从缺口的一边**顺时针**走到另一边。小的闭合圆（半径 4 到 8，细笔淡墨）是一圈涟漪 |
| `width` | 必填（没写 `centre` 和 `radius` 的 `circle` 除外，它用圆自己的 10） | 0.8–16 | 笔按到底的宽度。须 1.5–2，细枝 3，叶和尾巴 5–7，身子 9–12，一个看得见的点 4–9 |
| `press` | `plain` | 见下 | 提按：沿着笔顺哪里重哪里轻 |
| `ink` | 0.92 | 0.1–1 | 浓淡：1 焦墨，0.9 浓墨，0.5 淡墨，0.25 清墨 |
| `wet` | 0.5 | 0–1 | 干湿。0.7 以上墨会晕开，边是软的（身子、云、水汽）；0.3 以下看得见笔毛（老枝、一甩） |
| `dry` | 0.3 | 0–1 | 这一笔后半截干到什么程度（飞白） |
| `tint` | 0 | -1–1 | 一侧浓一侧淡。正数：顺着笔走的方向，左边浓 |
| `pace` | 1 | 0.1–3 | 这一笔的快慢：0.3 是一甩，0.5 利落，1.3 慢慢拖 |
| `pause` | 500 | 0–8000 | 写这一笔**之前**停多久（毫秒，闲时的速度）。0 是紧接着上一笔 |
| `liberty` | `free` | | 每次写出来可以多不一样：`still`（点、眼睛，必须落在原处）、`calm`、`free`、`leaf`（长叶长枝）、`quick`（一甩）、`sweep`（一气扫过）、`script`（字） |

提按 `press`（括号里是关键点 `[沿笔顺的位置, 力度]`，也可以自己写一组 2 到 12 个）：

| 名字 | 关键点 | 用在 |
|---|---|---|
| `plain` | 全程约 1，两头钝 | 杆、线、字的笔画 |
| `taper` | `[0,0.06] [0.5,1] [1,0.06]` 两头尖 | 闭着的眼、水纹、新月、船 |
| `fade` | `[0,1] [0.3,0.7] [1,0.05]` 落笔满、收笔尖 | 叶、喙、翅、尾巴尖 |
| `fly` | `[0,0.8] [0.12,1] [0.6,0.68] [1,0.05]` | 一甩、一撇、风 |
| `hair` | `[0,0.5] [0.15,0.9] [0.7,0.6] [1,0.04]` | 须、细枝、钓线 |
| `dot` | `[0,0.7] [0.45,1] [1,0.55]` | 眼睛、鼻子、水滴、花苞 |
| `press` | `[0,0.65] [0.3,1] [0.75,0.9] [1,0.5]` | 湿笔按一下：鸟的身子、花瓣 |
| `peak` | `[0,0.55] [0.45,1] [0.56,1] [1,0.55]` | 中段重：一只耳朵、一道拱 |
| `swell` | `[0,0.45] [0.42,1] [1,0.38]` | 一道钝头的弧 |
| `leaf` | 落、满、细、再满、出尖 | 兰叶、长草 |
| `ripple` | 起伏三次、收笔尖 | 水、烟 |

`fade`、`fly`、`hair` 的尖在**收笔**那头：想让尖朝外，就从里往外写。尖角一笔写会被走圆：三个点加 `peak` 是一只圆润的耳朵；要一个空心的尖（"^"）就分两笔。**实心的、有平底的形状**（斗笠、船身、山）用一笔宽笔，中间重两头轻，让路径微微上拱。

## 让它动的三个字段

这是小品和一幅画的全部区别。

| 字段 | 意思 | 例子 |
|---|---|---|
| `"fleeting": 毫秒` | 这一笔写完之后过这么久，自己干去 | 半空里的鱼、溅起的水、飘走的 z、扑一下的翅 |
| `"replaces": n` 或 `[n, m, ...]` | 这一笔开始写时，第 n 笔（从 0 数；时间表里方括号中的就是这个编号）干去：**同一样东西换了个样子**。一样东西由几笔组成时，用数组一次替掉它们 | 尾巴放着 → 尾巴翘起（替掉放着的那笔）；一条三笔的鱼游到别处（`replaces: [9, 10, 11]`） |
| `"moved": true` | 这一笔开始写时，这幅小品此前写的**所有**墨都干去：**原来的东西走了** | 雀原本站着 → 一笔翅膀写在远处，站着的雀就没了 |

用法的要点：

- **动一下再回来**：三笔。原样（第 n 笔）；变样（`replaces: n`，`fleeting: 500`）；再写一遍原样。猫的尾巴就是这样甩的。
- **一样东西走远**：在越来越远的地方写它，一次比一次小、淡，每一次都 `fleeting`，第一次带 `moved`。
- **连着写**：`"pause": 0`，一笔紧接一笔，像一口气画完的（鱼身、尾巴的两叉）。
- **一甩**：`pace` 0.3 到 0.4，`liberty: "quick"`。
- **顿**：要紧的一笔之前 `pause` 1200 以上，像在想，或者像它在看你。
- **干去不是一瞬间**：一笔被替掉、被带走之后，大约 0.3 秒才淡干净。快的连续动作里，上一个样子的淡影和下一个样子会同时在纸上一小会儿，这是正常的，像动作的余影。只有**两个都是满墨**才是错。
- 不要所有笔都一样快、停得一样久（校验器会提醒）。**快慢和停顿就是它的性格。**

### `answer`：被撞见了

闲时的小品正写着或停着的时候，主人的指针碰到头像，它会先演 `answer` 里的几笔，然后收场。没有 `answer` 的就直接收场。

- `answer` 里的笔也按闲时的速度写，播放时是 0.3 倍，总共不超过 5 秒。
- `answer` 里的 `replaces` 指的是 **`strokes` 里**的第几笔（睁开一只眼：替掉闭着的那只）；`moved` 是 `strokes` 里写的全部干去。没被替掉的，在回应演完时一起收。
- 好的回应是**这样东西自己的反应**：猫睁一只眼，雀飞走，蛇把刚添的脚擦掉。

## 趣味

- **拿圆来玩。** 最好的小品都在回答一个问题："这个圆还可以是什么？"
- **几笔就够。** 五到十二笔最好（这是建议，不是上限；一样东西要动一次就得多写一遍，为了那个转折多几笔是值得的，为了细节不值得）。头像很小，画不了细节，也不需要。
- **当心圆里长出脸和符号。** 圆本身像一张脸的轮廓、一个图标的外框。圆里**两个并排的点**是一双眼睛，再加一道弧就是一个表情；一个 ∪ 是笑；从一点张开的两笔是 ✓；圆里套一个小圆加一个黑点是个 App 图标。水滴、浮子、涟漪都可能凑出这些。看片时专门找一找，有就把它们错开、挪到圆外，或者换个朝向。
- **不要和已有的重复**：先看一眼 `pieces/` 里有什么。
- **不要演连续的位移。** 滚动、滑行、绕圈跑、弹跳，这些要靠很多个中间位置才成立，而每个位置干去都要时间，结果是一串重影。适合这支笔的动作是**离散的**：出现、消失、换一个样子、从这里到了那里（中间不画）。
- **有一个转折。** 写出一样东西只是一幅画；它做了一件事（跃出去了、打了个哈欠、被你吓跑了）才是一段小品。
- **中式的灵动，不是卡通。** 写意：鱼是一笔身子两笔尾，不画鳞；猫是两只耳朵两道闭着的眼。俏皮可以，卖萌不要；不画表情符号、爱心、星星、对话气泡。
- **墨分浓淡。** 至少一处浓（0.9 以上）一处淡（0.45 以下）。眼睛、喙、苞用浓墨点，身子用淡墨湿笔。
- **不要写字**，除非那个字就是画（z 是打呼）。
- **留白。** 纸很大，不要用满。一样东西，一个动作。

## 看片

`film.mjs` 通过时先打印时间表（每一笔什么时候写、写多久、什么时候干；方括号里是这一笔的编号，从 0 数，和 `replaces` 用的一样），再输出到 `--out` 的目录：

| 文件 | 是什么 |
|---|---|
| `<id>.film.png` | **每写完一笔拍一格**（左下角是时刻和笔的编号），最后三格是停着、正在收、结束。每格是整张纸（-100 到 200），红色虚线是头像的方框（0 到 100） |
| `<id>.still.png` | 刚写完那一刻，**放大三倍**看细节；右边是它在主人屏幕上的**实际大小**。认不认得出，看右边那个小的 |
| `<id>.answer.png` | 有 `answer` 时才有。第一格是指针来之前，后面九格是回应的过程 |

想看某一个时刻（比如一笔 `fleeting` 的东西还在的时候）：`node tools/film.mjs 你的小品.json --out shots --at 2300`，`still.png` 就是第 2300 毫秒。时刻从时间表里找。

片子是定格，看不到一笔正在写的过程，但看得到**先后**：谁先出现，谁在谁干去之后出现，什么时候纸上最满。配合时间表一起看。文件按 `id` 命名，所以 `id` 不要和别的小品重。

## 自查

逐条回答。有一条答"否"就改。

1. **认得出吗？** 看 `still.png`，不看名字，说得出这是什么吗？右边实际大小的那个还认得出吗？
2. **动了吗？** 相邻的几格之间，有东西出现、消失、换了样子吗？只看片子，能讲出 `idea` 里那两句话吗？
3. **顺吗？** 有没有哪一格里，本该已经走了的东西还是满墨地留着（忘了 `moved`、`replaces`）？（淡淡的余影不算；东西和它激起的水纹同时在也不算。）
4. **和圆有关吗？** 把圆拿掉，这一段还成立吗？成立，说明它没在和圆玩。
5. **不脏吗？** 纸上最满的那一格，有没有几笔叠成一团黑？有没有哪几笔凑成了一张脸或一个符号？
6. **回到圆了吗？** 最后一格只剩一个干净的圆吗？
7. **场合对吗？** 闲时：够慢吗，留在头像附近吗？指针下：2 到 4 秒吗，第一笔就让人看出有事发生吗？
8. （有 `answer` 时）**回应得像它吗？** 看 `answer.png`：这是这样东西自己会有的反应吗？

## 例子

`pieces/` 里的小品都通过了校验。动手之前**至少读两份**，并运行 `node tools/film.mjs pieces/<名字>.json --out <你的输出目录>` 看它的片子，对照着读 JSON：这是学会"怎样用几笔和三个字段演一件事"最快的办法。

| 文件 | 场合 | 圆 | 演的是 | 看点 |
|---|---|---|---|---|
| `fish-leap.json` | 指针下 | keep，当池塘 | 鱼从缺口跃出，水花，水纹 | `fleeting`；`pause: 0` 连笔；东西出了方框 |
| `sparrow.json` | 指针下 | keep，当枝头 | 雀落在圆上，歪头，飞走 | `replaces` 歪头；`moved` 飞走；越远越小越淡 |
| `sprout.json` | 指针下 | keep，当土 | 缺口里长出一棵芽，一片叶被风带了一下 | 最简单的一种：六笔；`replaces` 加 `fleeting` 再写回 |
| `sleeping-cat.json` | 闲时 | keep，当猫身 | 睡猫，甩一下尾巴 | 闲时的节奏；`replaces` 加 `fleeting` 甩尾；`answer` 睁眼 |
| `yawn.json` | 闲时 | away | 圆打了个哈欠，飘出三个 z | 把圆本身重写成别的样子 |
