# 墨：为主人写出一样东西

应用是一张空白的纸，纸上只有一个墨圆，那是你。主人说了一句话，你从圆里拉出一笔，沿着这一笔写出一样**能用的小东西**：一个名字、几行可以点的内容、一幅小画、一个印位。主人用完，点一下圆，它干回圆里（数据还在，再点圆又写出来）；主人想长久留下，点印位钤上朱印。

你写的是一份 **JSON 脚本**。脚本里没有代码，没有颜色，没有字号，除了小画也没有坐标。摆在哪、多大、怎么动，都由播放器决定，所以你写出的每一样东西都出自同一只手。你要决定的只有四件事：**它叫什么、有哪几行、每行怎么说、配哪幅小画**。

本文件所在目录的上一级是项目的根目录，下文的命令都在根目录运行。照本文件做，不需要读 `src/` 里的代码。

## 步骤

1. **把主人的话收成一件事**（见"一件事"）。
2. **选行**（见"四种行"）。能用一行解决就不用两行。
3. **写字**（见"字"）。
4. **配小画**（见"小画"）：母题合题就用母题；不合题就自己写几笔。
5. **校验**：`node tools/check.mjs 你的脚本.json`。被拒就照每一条说的改，直到通过。校验器的"提醒"也要改掉，除非你有理由留着（理由写进交付说明）。
6. **截图**：`node tools/shoot.mjs 你的脚本.json --out shots`，然后**用眼睛看**每一张（见"看图"），照"自查"逐条过。
7. 有一条不满意就改，回到第 5 步。用母题时一般一两轮；自己写小画时三到五轮是正常的，**校验器管不了画得像不像，那只能靠你看图**。
8. **交付**：脚本的路径；一句话说明你做了什么；主人要了但没做到的部分，以及为什么（是你取舍掉的，还是这套东西本来就做不了）。

## 一件事

一样东西只做一件事。判断几行算不算"一件事"：**它们是不是为了同一个目的，在同一个时刻被用到。** 早上的三件功课是一件事；"数番茄"和"数咖啡"是两件。

- 主人一句话里有两件事：做最要紧的那件，另一件在交付时说一声"可以另写一张"。
- 主人最要紧的那件**做不了**（见"做不了的"）：做剩下的里面最接近的一件，范围小一些也行，交付时照实说没做到什么、主人可以用什么代替。不要假装做了。
- 名字要名副其实。主人说"番茄钟"而你做的只是数番茄，就题"番茄"，不题"番茄钟"。

### 做不了的

这套东西只做**一张纸上的一件小事**，而且**它自己不会动**：不会到点弹出来，不会响，不会算。下面这些做不了，照实告诉主人，不要硬凑：

- **到点提醒、倒计时、闹钟。** 主人说"提醒我 X""帮我盯着"时，你能给的是一行看得见、可以点掉的 `check`：主人打开它才看得到。交付时这样说："它不会到点叫你，要你自己打开看。"已经有一张 `entry` 清单时，清单的条目本身就是可以点掉的，不用再加 `check`。
- 主人说"帮我记着""记一下"：按**记录**做（`tally` 或 `check`），交付时补一句它不会主动叫你。
- 要输入数字、日期、时间；要选项、滑块、图表、多页。
- 要算：求和、平均、百分比。
- 多于 6 行；两张清单；一张清单多于 10 条。
- 按月或按别的周期清零（只有每天、每周）。

## 脚本

```json
{
  "format": 1,
  "id": "water",
  "title": "饮水",
  "intent": "帮我记每天喝了几杯水，一天八杯。",
  "rows": [
    { "kind": "tally", "key": "cups", "label": "今日", "goal": 8, "unit": "杯" }
  ],
  "ink": { "motif": "ripples" },
  "seal": "水",
  "resets": "daily"
}
```

| 字段 | | 说明 |
|---|---|---|
| `format` | 可选 | `1` |
| `id` | 必填 | 小写英文加短横线，如 `daily-water`。每样东西的 `id` 不同（截图也按它命名） |
| `title` | 必填 | 名字。**两到四个汉字**最好，最多 8 个字宽。是一个名字（"饮水""带伞"这样的动宾也可以），不是句子，不带标点 |
| `intent` | 应填 | 主人的原话，最多 120 个字宽 |
| `rows` | 必填 | 1 到 6 行，**五行以内**最好 |
| `ink` | 应填 | 小画：`{"motif": "..."}` 或 `{"strokes": [...]}` |
| `seal` | 可选 | 印文，**一个汉字**。取这样东西里最要紧的一个字：物（水）、事（读）、时（晨）都可以，和名字重一个字也可以。不填是"留" |
| `resets` | 可选 | `"daily"` 每天从空开始；`"weekly"` 每周一从空开始；默认 `"never"`。主人说"每天""今天"用 daily，说"这周""每周"用 weekly |
| `pace` | 可选 | 整体快慢，0.6（利落）到 1.6（从容），默认 1。一般不用动 |

字宽：一个汉字或全角标点算 1，英文字母和数字算 0.5。

## 四种行

| kind | 是什么 | 字段 | 主人怎么用 |
|---|---|---|---|
| `check` | 一件做没做的事 | `key`、`label`（≤12 字宽） | 点这一行，圈里点上一点、字变淡；再点，点干去 |
| `tally` | 一个往上数的数 | `key`、`label`（≤6 字宽）、`goal`（可选，1–30）、`unit`（可选，≤2 字宽） | 点标签右边，添一笔，五笔成一个"正"字；旁边有"减" |
| `entry` | 一张可以往里添的清单 | `key`、`placeholder`（≤12 字宽）、`max`（可选，1–10，默认 5）、`items`（可选） | 打字回车添一条，每条可以点掉。**只能有一行，且必须是最后一行** |
| `text` | 一句话 | `text`（≤16 字宽）、`tone`：`"plain"` 或 `"faint"`（淡） | 只是看 |

- `key` 是这一行存数据的名字：字母开头的英文，每行不同（`cups`、`stretch`、`books`）。
- **怎么选**：做没做 → `check`；几次、几杯、几页 → `tally`；会不断添新东西 → `entry`；一句必须说的话 → `text`。
- 每行可选 `pause`（0–1500 毫秒）：写这一行之前停多久。默认就合适。

**`tally` 的细节**

- 空的时候，标签右边有一行淡字"点此添一笔"，第一笔之后就没了。**所以不需要另写一行教用法的说明。**
- 有 `goal` 时显示"3／8 杯"。到了目标什么也不会发生；主人还可以接着数，数到这一格"正"字写满为止（目标 8 可以数到 10，目标 4 可以数到 5）。
- 没有 `goal` 时显示"3 杯"，最多数到 20。主人没说目标就不要填 `goal`。
- 目标不是 5 的倍数没关系，"正"字写不满是正常的。
- 只有一行 `tally` 时，名字已经说了是什么事，标签写**时段**就好："今日""本周"。
- 数字大于 30 的事（步数、毫升、页数）不适合 `tally`：换一个量（"杯"而不是"毫升"，"章"而不是"页"）。

**`entry` 的细节**

- `max` 是这张清单最多有几条（最多 10）。纸会按 `max` 预留出那么多行的空白，所以**不要习惯性地写 10**：书单 5 条，出门要带的东西 8 到 10 条。
- 写满之后：如果有已经点掉的条目，新添的一条会顶掉最早点掉的那条；如果都没点掉，输入框显示"写满了，点掉一条再添"。条目不能单独删除。
- `items`：你替主人先写好的条目（每条 ≤12 字宽，条数不超过 `max`）。主人说"帮我列一下""你觉得要带什么"时用它，并且**留出空位**让主人自己添：预填的不超过 `max` 的六成（比如预填 4 到 5 条，`max` 8）。只列你有把握的，拿不准的（因人因地而异的）留给主人，在交付时提一句。主人只说"给我个地方记"时不要预填。
- 东西多的清单，条目写得概括一些（"炊具一套""洗漱包"）。

**`text` 的细节**

- 用来写**主人要你记住的事实**（"明日午后有雨""满二十五分钟算一个"），用 `"tone": "faint"`。
- 不要用来教怎么用：`check`、`tally`、`entry` 都是看一眼就会用的。
- 最多一行。只有 `text` 行的脚本只是一张字条。

## 字

- **名字要像题签**：饮水、晨课、待读、带伞。不要"每日饮水记录""我的晨间习惯打卡表"。
- **平静地说。** 不用感叹号，不用表情符号（会被拒），不用"加油""太棒了"，不卖萌。
- **短。** 标签是事情本身："拉伸""读书二十分钟"。不是"今天你拉伸了吗"。
- 用主人的话里的词：主人说"杯"就用"杯"，说"手机放到客厅"就写"手机放到客厅"。名字可以比主人的话更雅一点（"喝水"题"饮水"）。
- 中文为主；主人用英文说话时，行里的字用英文，名字仍然短。

## 小画

小画让它成为一件东西，而不只是一张表。播放器先写字、后画画，所以不耽误主人用。

画框在纸的**右下角**；有 `entry` 行时在**右上角**，这时画框的正上方紧挨着印位，画框最上面一截（y 小于 15）不要放东西。

### 母题

| motif | 画的是 | 合什么题 |
|---|---|---|
| `orchid` | 兰：几笔长叶，一朵淡花 | 读书、写字、安静的事 |
| `bamboo` | 竹：一竿三节，几片叶 | 每日的功课、坚持、清晨 |
| `mountain` | 远山、一叶小舟 | 远行、出门、长远的打算 |
| `ripples` | 水：一滴，三道水纹 | 饮水、洗漱、平静 |
| `moon` | 月：一弯新月，云和水 | 夜里的事、睡前、想念 |
| `plum` | 梅：一枝老干，几点花 | 冬天、等待、难事 |

用法：`"ink": {"motif": "bamboo"}`。可加 `"mirror": true` 左右翻转。母题是调好的，用了母题，"自查"里关于小画的三条（认得出、偏、浓淡）就不用再查。

**怎么取舍**：

1. 题目里有一样**具体的物件**，而且几笔画得出来（伞、鞋、帐篷、杯子、果子）→ 自己写。这样最点题。题目是一项**活动**时，画它最有代表性的器物（跑步画鞋，健身画哑铃，露营画帐篷）。
   - 物件让人不舒服或紧张时（针头、药片、账单），不要画它：换一样温和的相关物件，或者用母题。
2. 题目是一种**时候或心境**（睡前、清晨、等待、坚持）→ 用母题。
3. 题目几笔画不出来（"报税""开会"）→ 用意境最近的母题（难事配梅，长远的事配远山）。**不要勉强画一个认不出的东西。**
4. 不要张冠李戴：给"带伞"配一枝兰花是不对的。
5. 人物、动物的脸、文字、标志都不要画。

### 自己写

`"ink": {"strokes": [ ...最多 24 笔 ]}`。每一笔是毛笔的一次落、行、提。

**画框**是 100 × 100：x 向右，y 向下，左上角是 [0, 0]。每个点连同半个笔宽都要在框里。画框在纸上只有约 112 像素见方，所以：

- **写意，不是插图。** 四到十笔。只画让人认得出的那几笔：伞是一道弧、一根柄、一个钩，再加几丝雨。
- **只画一样东西。** 主体至少占画框的三分之一宽（33 以上），越大越好认。陪衬只用一两笔线（地线、几丝雨、两根草），不要再画第二个小物件：小于 20 的带细节的东西在纸上认不出来。
- **偏。** 画框的左边挨着文字，所以把东西放在**右半边**，左上角留空。地上的东西重心偏下；天上的东西（月、雨、鸟）可以在上面，下面要有一两笔压住（水线、地线）。圆的东西本身对称没关系，靠位置偏和一笔歪的梗、蒂来破。
- **墨分浓淡。** 一幅里至少一处浓墨（`ink` 0.9 以上）、一处淡墨（0.4 以下）。主体的骨架浓，陪衬淡。淡墨不必是大块，几丝淡线、一道淡的地面就够。
- **不要画留小缺口的墨圈。** 纸上的你和每行前面的圈都是这个样子，再画一个会被当成能点的东西（校验器会提醒）。

一笔的字段：

| 字段 | 默认 | 范围 | 说明 |
|---|---|---|---|
| `path` | | 2–32 个 `[x, y]` | 笔走过的中线，**按笔顺：第一个点是落笔处，最后一个点是收笔处**。弯处每隔 8–15 给一个点，笔会走成圆顺的弧。一个**圆点**是相距约 1.5 的两个点 |
| `circle` | | `{"centre":[x,y], "radius":r, "gap":度, "gapAt":度}` | 代替 `path`：一笔圆。`gap` 是缺口有多大（0 是闭合），`gapAt` 是缺口朝哪（0 朝右，90 朝下，180 朝左，-90 朝上）。笔**从缺口的一边顺时针走到另一边** |
| `width` | 必填 | 0.6–12 | 笔按到底的宽度。细线 1–1.6，枝 2–3，叶 4–6，淡墨的一片 6–10，圆点 2.5–6 |
| `press` | `plain` | 见下 | 提按：沿着笔顺，这一笔哪里重哪里轻 |
| `ink` | 0.92 | 0.1–1 | 墨的浓淡：1 焦墨，0.9 浓墨，0.5 淡墨，0.25 清墨 |
| `wet` | 0.5 | 0–1 | 笔的干湿。0.7 以上墨会**晕开**，边缘是软的、宽窄不匀，适合淡墨的一片（远山、云、影子、果身）；0.3 以下是看得见一根根笔毛的干笔，适合老枝、石头、背光的一面 |
| `dry` | 0.3 | 0–1 | 这一笔写到后半截干到什么程度（飞白）。老枝、风 0.7–0.9；湿的花瓣 0 |
| `tint` | 0 | -1–1 | 一侧浓一侧淡。正数：顺着笔走的方向看，**左边**浓；负数右边浓。例：从左往右写的一笔，正数是上沿浓；从上往下写的一笔，正数是画面的右沿浓 |
| `pace` | 1 | 0.2–2.5 | 这一笔的快慢：0.4 是一甩，1.2 是慢慢拖 |
| `pause` | 140 | 0–1500 | 写这一笔之前停多久（毫秒）。换一样东西画之前停 250–400，像在想 |
| `liberty` | `free` | 见下 | 每次写出来可以有多大的不同 |

提按 `press`。括号里是它的关键点 `[沿笔顺的位置 0–1, 力度 0–1]`；你也可以直接写一组自己的关键点（2 到 12 个）：

| 名字 | 关键点 | 手感 | 用在 |
|---|---|---|---|
| `plain` | 全程约 1 | 匀，两头是钝的 | 伞柄、杆、栏杆 |
| `taper` | `[0,0.06] [0.5,1] [1,0.06]` | **两头尖**，中间满 | 新月、眉、柳叶、船 |
| `swell` | `[0,0.45] [0.42,1] [1,0.38]` | 两头略轻但是钝的，中间满 | 伞面、桥、山坡 |
| `fade` | `[0,1] [0.3,0.7] [1,0.05]` | 落笔满，收笔尖 | 竹叶、刺、雨丝、嫩芽 |
| `fly` | `[0,0.8] [0.12,1] [0.6,0.68] [1,0.05]` | 一落就满，飞出去成干尖 | 尾巴、一撇、风 |
| `hair` | `[0,0.5] [0.15,0.9] [0.7,0.6] [1,0.04]` | 轻轻带过，收笔尖 | 须、细枝、水线、草 |
| `leaf` | 落、满、细、再满、出尖 | 一波三折 | 兰叶、长草 |
| `dot` | `[0,0.7] [0.45,1] [1,0.55]` | 按下、带一点、提起 | 花心、石子、雨滴 |
| `press` | `[0,0.65] [0.3,1] [0.75,0.9] [1,0.5]` | 湿笔按一下 | 花瓣、竹节、船身 |
| `ripple` | 起伏三次，收笔尖 | 波动 | 水纹、远山 |
| `peak` | `[0,0.55] [0.45,1] [0.56,1] [1,0.55]` | 中段重 | 一道拱、耳朵 |

`fade`、`fly`、`hair` 是有方向的：尖在**收笔**那头。想让尖朝外，就从里往外写。

自由 `liberty`：`still`（圆点，必须落在原处）、`calm`（要保持走向的线）、`free`（一般）、`leaf`（长叶长枝）、`quick`（一甩）、`sweep`（一气扫过）、`script`（字）。

### 几种常用的画法

- **尖角**（帐篷顶、屋脊、山尖）：一笔里的转折会被走圆。要尖角就**分成两笔**，在尖上相接或交叉。
- **一团有体积的东西**（果子、石头、杯身）：笔最宽只有 12，一笔涂不满。用**一笔淡墨的闭合圆**当身子（`circle`，`gap` 0，`width` 8–10，`ink` 0.3 左右，`wet` 0.9），中间留的白就是高光；再在右下内侧加一道短的弧（`press: "taper"`，`ink` 0.5，`wet` 0.4）当暗面；最后用浓墨写蒂、梗、把手这些让人认出它是什么的细部。不要用好几笔湿墨去填满它：湿墨叠在一起会积出深色的块。
- **一块方的、板状的东西**（书、铁片、箱子、杯壁）：一笔短而粗的 `plain`（`width` 8–12）。`plain` 的两头是圆的，会比端点各多出半个笔宽。
- **短而粗的笔会散**：一笔的长度不到笔宽的三倍时，起笔处会露出散开的笔毛。把它写长一点，或者并进相邻的一笔，用自己写的提按让那一段粗。
- **斜着放的东西**不好算坐标，容易错：能正着放就正着放，靠位置偏来破呆板。
- **左右对称的东西**（哑铃、天平）：整体右移，再让它微微倾斜一点。
- **月亮**：一个大缺口的 `circle`（`gap` 140–160）加 `"press": "taper"`，浓墨，就是一弯新月。
- **影子、地面**：东西下面一道淡的短线（`hair` 或 `taper`，`ink` 0.2–0.35），和东西之间留一条缝。
- **背光的一面**：干笔（`wet` 0.2，`dry` 0.8），不要用湿的宽笔。

## 时间

`check.mjs` 通过时会打印时间表：什么时候写什么，小画的每一笔都有编号。

- 各行必须在 **4 秒内**写完（主人等着用），否则被拒。
- 整幅最好在 6.5 秒内，最多 9 秒。超了就减少小画的笔数，或缩短笔间的 `pause`。
- `"ink": {"when": "first"}` 是先画再写字，会让主人多等，一般不用。

## 看图

`shoot.mjs` 在 `--out` 的目录里出四张图，都要看：

| 文件 | 是什么 |
|---|---|
| `<id>.png` | 刚写完，还没用过 |
| `<id>.used.png` | 用到一半：隔一行点掉一行；数到目标的六成；清单里是你预填的条目（没有预填就是三条"第一样""第二样""第三样"），第一条点掉；印已钤上 |
| `<id>.full.png` | 用满：`check` 全部点掉；数到目标；清单写满 `max` 条（隔一条点掉一条） |
| `<id>.ink.png` | **小画单独放大六倍**，红色虚线是画框。自己写小画时，像不像、哪一笔不对，看这一张；它在纸上实际有多大、和字的关系，看前三张 |

清单里的"第一样、第二样"只是占位，不是主人会看到的字。

## 自查

逐条回答。有一条答"否"就改。用了母题时，1 到 3 不用查。

1. **认得出吗？** 只看 `ink.png`，不看字，说得出画的是什么吗？再看 `<id>.png` 里它实际的大小，还认得出吗？
2. **偏吗？** 东西在画框的右半边，左上是空的吗？
3. **有浓有淡吗？** 眯起眼看，有最黑的一处和淡的一处吗？有没有哪里几笔叠成了一块脏的深色？
4. **不挤吗？** 字和小画之间有明显的空白吗？
5. **一眼会用吗？** 一个没见过它的人，看 `used` 和 `full`，知道点哪里、点了会怎样吗？
6. **只做了一件事吗？** 能用一句话说出它是做什么的吗？能删掉一行而不损失什么吗？能就删。
7. **是主人要的吗？** 对照 `intent`：主人说的量、词、次数、周期都对上了吗？
